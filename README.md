# Electricity Management System — Web Edition

Converted from the Java Swing Electricity Management System into a responsive browser application.

## Features
- Dashboard
- Consumer add/search/update/delete
- Residential, Commercial and Industrial consumer types
- Same electricity slab calculation as the Java project
- ₹100 fixed charge
- Bill generation
- Bill history and Consumer ID search
- Reports and statistics
- Export/import JSON
- Browser localStorage persistence

## Deploy on Vercel
1. Put `index.html`, `style.css`, `app.js`, and `vercel.json` in a GitHub repository.
2. Open Vercel and choose **Add New Project**.
3. Import the GitHub repository.
4. Framework Preset: **Other**.
5. Build Command: leave empty.
6. Output Directory: `.`
7. Deploy.

No Java, Maven, database or backend is required for this demo version.
